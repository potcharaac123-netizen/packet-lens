# PacketLens

เว็บแอปสำหรับอ่านไฟล์ `.pcap` และ `.pcapng` แบบเข้าใจง่ายสำหรับคนทั่วไป ทำงานบนเบราว์เซอร์ 100% (ไม่ส่งข้อมูลออกนอกเครื่อง)

## ฟีเจอร์หลัก
- **รองรับไฟล์ `.pcap` และ `.pcapng`**: แกะข้อมูลบนเบราว์เซอร์ทันที
- **Overview & Story**: สรุปเว็บไซต์/โดเมนที่ถูกเรียกใช้งาน พร้อมแจ้งเตือนจุดผิดปกติ (`DNS NXDOMAIN`, `TCP RST`, `HTTP 4xx/5xx`, HTTP ไม่เข้ารหัส)
- **Sequence Diagram**: แผนภาพลำดับการสื่อสารระหว่างเครื่องตามเวลา (ซ่อน TCP ACK เปล่าได้)
- **Network Topology**: แผนผังความสัมพันธ์แบบลากวางได้ แยกสีตามบทบาท (Local, Gateway, DNS, External)
- **Packet Inspector**: อธิบายแพ็กเก็ตเป็นภาษาคน + แยกชั้นโปรโตคอล + ดู Raw Hex/ASCII ได้
- **รองรับ 2 ภาษา**: ไทย / อังกฤษ (`TH / EN`)

## วิธีเปิดใช้งานบน Windows (ง่ายที่สุด)
1. ดาวน์โหลดโปรเจกต์นี้ (Code -> Download ZIP แล้วแตกไฟล์)
2. ดับเบิลคลิกไฟล์ `start-packet-lens.bat`
3. เมื่อเลิกใช้งาน แค่ปิดหน้าต่างสีดำ เซิร์ฟเวอร์จะหยุดทำงานทันที

## วิธีรันสำหรับนักพัฒนา
```bash
npm install
npm run dev
```
